# Wine Prediction Using Machine Learning

## Project Overview

Wine quality prediction is a Machine Learning project that focuses on analyzing wine-related data and predicting wine quality based on its characteristics.

The project uses data analysis and Machine Learning techniques to identify patterns in the dataset and understand how different features contribute to wine quality.

The main purpose of this project is to demonstrate how Machine Learning can be applied to a real-world prediction problem using Python.

## Project Objectives

- Understand and explore the wine dataset.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Identify important patterns and relationships in the dataset.
- Apply Machine Learning techniques for wine prediction.
- Evaluate the performance of the prediction model.

## Dataset Information

The project uses the `wine_quality_merged (2).csv` dataset.

The dataset contains wine-related information used for analysis and prediction.

The dataset is used to explore the relationship between wine characteristics and the prediction target.

**Dataset File:** `wine_quality_merged (2).csv`

**Target Variable:** Wine quality or the prediction target defined in the notebook.

## Technologies Used

- **Programming Language:** Python
- **Development Environment:** Google Colab / Jupyter Notebook
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn 
- **Domain:** Data Science and Machine Learning

## Project Workflow

1. Data Collection – Loading the wine dataset.
2. Data Understanding – Exploring the dataset and understanding its features.
3. Data Cleaning – Checking and handling missing or inconsistent data.
4. Exploratory Data Analysis – Analyzing patterns and relationships using visualizations.
5. Data Preprocessing – Preparing the dataset for Machine Learning.
6. Model Training – Applying Machine Learning techniques to the prepared data.
7. Model Evaluation – Evaluating the prediction model's performance.
8. Prediction – Generating predictions using the trained model.

**Step 1:** Clone or download this repository.

```bash

```

**Step 3:** Open `Wine_prediction.ipynb` using Jupyter Notebook, VS Code or Google Colab.

**Step 4:** Make sure the dataset file is available in the same project directory.

**Step 5:** Run the notebook cells in sequence to perform data analysis, train the model and generate predictions.
